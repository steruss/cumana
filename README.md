# Cumana Ste

Prossima Cumana da La Trencia a Montesanto e coincidenza con la Linea 2 per Garibaldi, andata e ritorno.

- Pagina: https://steruss.github.io/cumana/
- Gli orari stanno tutti in `data.js`.
- Dopo ogni modifica, aumenta la versione (es. 2.0 → 2.1) sia in `index.html` (`VERSIONE`) sia in `sw.js` (`CACHE`): il telefono scarica i file nuovi e la versione si vede in fondo alla pagina.
